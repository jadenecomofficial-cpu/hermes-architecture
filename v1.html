Load-bearing principles

Lean spawn. A profile loads a tiny kernel + ONLY its domain skills — never the 9-skill fat load that burned 180k.
JIT skills. Skills/protocols load just-in-time per task, not all-at-start.
Cycle, don't compress. Long work → write to disk → respawn fresh, not lossy compaction.
Distilled briefs. Children return verdicts (~2k), not raw reads (~60k+).
Effort + model routing. Trivial → cheap/local; hard → frontier muscle. A trivial task shouldn't cost >50k.
Cost-capped. Bulk → Gemini/Codex/NotebookLM (~$0); never burn the Claude window 24/7.
